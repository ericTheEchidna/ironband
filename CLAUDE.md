# Ironband — Godot Frontend

Godot 4.6 frontend for the Ironband game. Pure display layer — no game logic here.
Communicates with the ibp-engine C++ engine via the Protohack protocol.

## Project slug
`ironband` (Memex ID 30)

## Engine
ibp-engine (`~/source/ibp-engine`) — launched as subprocess, speaks Protohack over stdin/stdout.

## World data
`worlds/cheia/hex_grid.json` — symlinked from ibp-engine world directory.
Generated by `ibp-engine/tools/azgaar_to_hex.py` from `worlds/cheia/azgaar.json`.

## Scenes
- `scenes/WorldMap.tscn` — hex world map display, Camera2D pan/zoom

## Godot version
4.6, GL Compatibility renderer
