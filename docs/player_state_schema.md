# Player State Schema — v1

Canonical schema for player state shared between `ibp-engine` (C++) and `ironband` (GDScript).  
The engine owns persistence (`worlds/cheia/player_state.json`). The frontend holds a live in-memory copy and pushes changes via Protohack.

---

## Full Example

```json
{
  "schema_version": 1,
  "inventory": {
    "rusted knife": { "qty": 1, "type": "weapon", "condition": "worn" },
    "dried herbs":  { "qty": 3, "type": "consumable", "condition": "pristine" }
  },
  "ground_items": {
    "373,252": ["old coin", "leather strip"]
  },
  "visited_hexes": [
    { "q": 373, "r": 252, "count": 3 },
    { "q": 374, "r": 252, "count": 1 }
  ],
  "npcs": {
    "npc_001": {
      "name": "Aldric", "culture": "Celt", "hex": "373,252",
      "faction_id": 4, "last_said": "Safe travels.", "met_count": 2
    }
  },
  "quests": [
    {
      "id": "q001", "type": "fetch", "title": "Aldric's Debt",
      "description": "Bring a compass to Aldric at the river ford.",
      "target_item": "compass", "target_hex": "373,252",
      "target_npc_id": "npc_001", "status": "active"
    }
  ],
  "journal": [
    { "ts": 1749550000, "type": "encounter", "hex": "373,252", "text": "Met Aldric the trader near the river ford." },
    { "ts": 1749550120, "type": "item",      "hex": "374,252", "text": "Found a rusted knife in the Temperate Forest." }
  ],
  "journal_summary": "Traveled from Temperate Forest through Grassland. Met Aldric near the river.",
  "chat_summary": "Discussed the road ahead and the missing compass with Aldric."
}
```

---

## Top-level Fields

| Field | Type | Description |
|-------|------|-------------|
| `schema_version` | `int` | Incremented on breaking changes. Reader must reject or migrate unknown versions. |
| `inventory` | `object` | Items carried by the party. Keys are lowercase item names. |
| `ground_items` | `object` | Items left on the ground. Keys are hex strings `"q,r"`. |
| `visited_hexes` | `array` | Ordered arrival history, newest last. Capped at 50 entries. |
| `npcs` | `object` | Encountered NPCs. Keys are stable npc IDs (`npc_NNN`). |
| `quests` | `array` | All quests (any status). |
| `journal` | `array` | Event log, newest last. Capped at 100 entries. |
| `journal_summary` | `string` | Ollama-compressed summary of older journal entries. |
| `chat_summary` | `string` | Ollama-compressed summary of older chat turns. |

---

## inventory entry

```json
"rusted knife": { "qty": 1, "type": "weapon", "condition": "worn" }
```

| Field | Type | Values |
|-------|------|--------|
| `qty` | `int` | `≥ 1` |
| `type` | `string` | `weapon` · `tool` · `consumable` · `trinket` |
| `condition` | `string` | `pristine` · `worn` · `damaged` · `broken` |

Condition is flavor-only in v1. Mechanical effects deferred.

---

## ground_items entry

```json
"373,252": ["old coin", "leather strip"]
```

Key format: `"q,r"` (axial hex coordinates, no spaces).  
Values: array of lowercase item name strings. Empty arrays may be omitted.

---

## visited_hexes entry

```json
{ "q": 373, "r": 252, "count": 3 }
```

| Field | Type | Description |
|-------|------|-------------|
| `q` | `int` | Axial q coordinate |
| `r` | `int` | Axial r coordinate |
| `count` | `int` | Cumulative visit count (≥ 1) |

Entries are unique by `(q, r)`. Oldest entry evicted when list exceeds 50.

---

## npcs entry

```json
"npc_001": { "name": "Aldric", "culture": "Celt", "hex": "373,252", "faction_id": 4, "last_said": "Safe travels.", "met_count": 2 }
```

| Field | Type | Description |
|-------|------|-------------|
| `name` | `string` | Display name (generated by Ollama from culture) |
| `culture` | `string` | Culture name from cultures.bin |
| `hex` | `string` | Last known hex `"q,r"` |
| `faction_id` | `int` | Realm/faction ID from hex data (0 = none) |
| `last_said` | `string` | Last line of dialogue; injected into re-encounter Haiku prompt |
| `met_count` | `int` | Number of encounters with this NPC |

---

## quests entry

| Field | Type | Values / Description |
|-------|------|----------------------|
| `id` | `string` | Stable unique ID (`q001`, `q002`, …) |
| `type` | `string` | `fetch` · `find` · `talk` |
| `title` | `string` | Short display title |
| `description` | `string` | Player-facing description |
| `target_item` | `string` | Item name required (`fetch` only; omit otherwise) |
| `target_hex` | `string` | Destination `"q,r"` (`fetch` / `find`; omit for `talk`) |
| `target_npc_id` | `string` | NPC key (`talk` / `fetch`-to-NPC; omit otherwise) |
| `status` | `string` | `pending` · `active` · `completed` · `failed` |

**Completion detection:**
- `fetch` — player carries `target_item` and arrives at `target_hex`
- `find` — player visits `target_hex`
- `talk` — player encounters NPC matching `target_npc_id`

---

## journal entry

| Field | Type | Values / Description |
|-------|------|----------------------|
| `ts` | `int` | Unix epoch seconds |
| `type` | `string` | `encounter` · `item` · `quest` · `npc` |
| `hex` | `string` | `"q,r"` where the event occurred |
| `text` | `string` | Human-readable log line |

Cap: 100 entries. When > 50, Ollama compresses the oldest 25 into `journal_summary`.

## Protohack Protocol

### Engine → Frontend (on handshake complete)
```
world.player_state data=<url-encoded-json>
```

### Frontend → Engine (debounced, max once per 2 s)
```
> player.state_sync data=<url-encoded-json>
```

### Engine → Frontend (after successful write)
```
world.state_ack
```

---

## Migration Policy

| Change type | Action |
|-------------|--------|
| Add optional field | No version bump required |
| Rename or remove field | Bump `schema_version` |
| Change field type | Bump `schema_version` |
| Add enum value | No version bump required |

The engine logs a warning and returns an empty state if it reads an unknown `schema_version`. It never silently overwrites a newer schema with an older one.
